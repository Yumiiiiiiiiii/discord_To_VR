# 自動アップデート

0.2.0 以降のインストーラー版は、新版の確認からダウンロード、署名検証、インストール、再起動まで自動で行います。起動から約15秒後、その後は12時間ごとに GitHub Releases の更新情報を確認します。

設定の入力中は、ダウンロード後に待機します。保存またはキャンセルで設定を閉じると適用します。適用直前に Discord・Bot・XSOverlay の接続を停止し、更新後のアプリが接続を再開します。その間の通知は受信できないことがあります。

サイドバーの「アプリの更新」で現在のバージョン、進行状況、最終確認時刻を確認できます。「今すぐ確認して更新」で確認を開始できます。自動アップデートをオフにすると定期確認と自動適用を停止します。ダウンロード中・待機中にオフにした場合も適用を止めます。インストーラー起動後は切り替えできません。オフのまま手動確認すると、新版の有無だけを表示します。

ZIP 版は更新の確認だけに対応します。自動適用にはインストーラーで登録された場所からの起動が必要です。コピーした実行ファイルから別の場所へ更新することを防ぎます。旧版 0.1.0 には更新機能がないため、最初の 0.2.0 導入は手動でインストーラーを実行してください。受信診断（`-debug`）中は更新の通信・適用を行いません。

## 安全性と通信

更新情報は `https://github.com/Yumiiiiiiiiii/discord_To_VR/releases/latest/download/latest.json` から取得します。更新ファイルは同じリポジトリの HTTPS インストーラーだけを受け付け、埋め込まれた公開鍵でファイルとバージョンの署名を検証します。古い版への更新、改ざん、署名と異なるバージョンの指定は拒否します。確認・ダウンロード・検証の失敗では現在のアプリや接続を変更しません。インストーラーを起動できなかった場合は通知接続を再開します。

GitHub と配信先 CDN には IP アドレス、User-Agent など通常の HTTP 通信情報が伝わります。Discord の認証情報、会話の本文、ユーザー ID・チャンネル ID は更新通信に含めません。更新設定は `%APPDATA%\discord-to-vr\updates.json` に保存し、Discord の `config.json` とは別に管理します。

更新用署名は Windows の Authenticode 署名とは別のものです。SmartScreen の発行元表示を変更する機能ではありません。

以前の `%APPDATA%\io.github.yumiiiiiiiiii.discord-to-vr\updates.json` は、新しい保存先に更新設定がない場合だけコピーして引き継ぎます。元のファイルは残し、自動アップデートをオフにしていた設定も維持します。移行に失敗した場合は自動更新を停止し、更新画面に案内を表示します。

配布者向けの署名・ビルド・Release 公開手順は [開発ガイド](DEVELOPMENT.md) にまとめています。
